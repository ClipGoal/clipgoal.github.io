DATENSCHUTZERKLÄRUNG

Stand: November 2026

1. Wer ist verantwortlich?

Verantwortlich für ClipGoal und die Anwendung „ClipForge“ ist der Betreiber der Kanäle ClipGoal / ClipGoal World. Kontakt: clip.goal@gmx.de

2. Was ist ClipForge?

ClipForge ist ein privates Programm, das ausschließlich auf dem eigenen Computer des Betreibers läuft. Es erstellt kurze Video-Clips und lädt sie auf die eigenen YouTube-Kanäle des Betreibers (ClipGoal und ClipGoal World) hoch. Es gibt keine Nutzerkonten für Dritte, keine Registrierung und keinen Verkauf von Daten.

3. Welche Google-/YouTube-Daten werden genutzt?

ClipForge nutzt die YouTube Data API über eine Google-Anmeldung (OAuth) mit genau zwei Berechtigungen:

  • youtube.upload – um Videos auf die eigenen Kanäle hochzuladen,
  • youtube.readonly – um den Namen des verbundenen Kanals anzuzeigen und Aufrufzahlen der eigenen Videos abzufragen.

Die Anmelde-Schlüssel (Tokens) werden nur lokal auf dem Computer des Betreibers gespeichert. Sie werden an niemanden weitergegeben. ClipForge liest keine Daten anderer Nutzer, keine privaten Nachrichten und keine Kontaktdaten.

Die Nutzung von Daten, die ClipForge über Google-APIs erhält, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung („Limited Use“). Es gelten zusätzlich die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

4. Zugriff widerrufen

Der Zugriff von ClipForge auf ein Google-Konto kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Danach werden die lokal gespeicherten Schlüssel gelöscht.

5. Diese Webseite

Diese Webseite wird über GitHub Pages (GitHub Inc., USA) bereitgestellt. Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie die IP-Adresse in Server-Protokollen; siehe die Datenschutzerklärung von GitHub. Die Seite selbst setzt keine Cookies, nutzt keine Analyse- oder Tracking-Dienste und lädt keine Schriften von Drittanbietern.

6. Videos auf ClipGoal

Die Clips zeigen Ausschnitte aus öffentlichen Streams; die Urheber werden in jeder Videobeschreibung genannt. Wer als Streamer die Entfernung eines Clips wünscht, kann sich jederzeit an die oben genannte Adresse wenden.

7. Deine Rechte

Du hast das Recht auf Auskunft, Berichtigung, Löschung und Einschränkung der Verarbeitung deiner Daten sowie ein Beschwerderecht bei einer Datenschutz-Aufsichtsbehörde. Wende dich dazu an die oben genannte Kontaktadresse.

PRIVACY POLICY

Last updated: November 2026

Summary

ClipForge is a private application that runs only on the operator's own computer. It uploads short video clips to the operator's own YouTube channels (ClipGoal and ClipGoal World) using the YouTube Data API with the scopes youtube.upload (upload videos) and youtube.readonly (show the connected channel name and view counts of our own videos). OAuth tokens are stored locally only and are never shared, sold or transferred. No data of other users is accessed.

ClipForge's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. By using our channels you are also subject to the YouTube Terms of Service and the Google Privacy Policy.
